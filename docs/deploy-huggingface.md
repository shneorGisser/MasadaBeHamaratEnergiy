# שיתוף עם חברים — Hugging Face Spaces

**למה דווקא כאן:** Space מסוג Docker מריץ את כל האפליקציה (FastAPI, הפותר וה-React) בחינם,
ונותן קישור קבוע. החיסרון: בלי אחסון מחובר, הנתונים נמחקים בכל הפעלה מחדש של ה-Space.
לאיסוף משוב זה מספיק. לשימוש קבוע עוברים ל-Cloud Run (`docs/deploy-cloud-run.md`).

## מה המשתמשים מקבלים

- **מרחב פרטי לכל דפדפן**, בלי הרשמה. מי שנכנס לא רואה פרויקטים של אחרים. השרת מזהה את הדפדפן
  לפי עוגייה (`VEL_WORKSPACES=cookie`), ומחזיר 404 על כל פרויקט, ריצה, סט מדידות או דו״ח שלא שלו.
- **קישור שיתוף לפרויקט** ("שיתוף הפרויקט" בתוך הפרויקט). מי שפותח אותו מקבל **עותק** במרחב שלו.
  את המקור הוא לא יכול לשנות. אפשר לבטל את הקישור.
- **המשך ממכשיר אחר** (בעמוד הפרויקטים). זה קישור אישי, אסור לשלוח אותו לאחרים: מי שמחזיק בו
  יכול לערוך את כל הפרויקטים.
- **כפתור "משוב"** בכל עמוד. ההודעות נשמרות עם העמוד וסוג הדפדפן. אתה קורא אותן ב-`/feedback`.

## הקמה (פעם אחת, כרבע שעה)

1. נרשמים ל-[huggingface.co](https://huggingface.co).
2. **New → Space**:
   - שם, למשל `virtual-energy-lab`;
   - **Space SDK: Docker → Blank**;
   - חומרה: **CPU basic** (חינם);
   - **Public**.
3. בלשונית **Files** של ה-Space מחליפים את `README.md` ומוסיפים `Dockerfile`, בתוכן של שני
   הקבצים שבתיקייה `deploy/huggingface` ב-GitHub. ההעלאה היא דרך **Add file → Upload files**, או
   **Create new file** והדבקה.
4. **Settings → Variables and secrets → New secret**:
   - שם: `VEL_ADMIN_TOKEN`;
   - ערך: מחרוזת אקראית ארוכה.
   זה המפתח לעמוד המשוב. בלעדיו העמוד חסום.
5. הבנייה מתחילה לבד ולוקחת כמה דקות (בלשונית **Logs**). היא מורידה את הקוד העדכני מ-GitHub.
6. הקישור לשיתוף הוא הכתובת הישירה: `https://<שם-המשתמש>-<שם-ה-space>.hf.space`.
   עדיף לשלוח אותה ולא את `huggingface.co/spaces/...`. הכתובת השנייה מציגה את האפליקציה בתוך
   מסגרת, ושם דפדפנים שחוסמים עוגיות של צד שלישי עלולים לא לשמור את המרחב.

## עדכון לגרסה חדשה

**Settings → Factory rebuild.** ה-Dockerfile מוריד את `main` העדכני מ-GitHub, ולכן אין מה להעלות.
כל פריסה מחדש מוחקת את הנתונים, אלא אם חובר אחסון (בהמשך).

## קריאת המשוב

פותחים `https://<הכתובת>/feedback` ומזינים את `VEL_ADMIN_TOKEN`. המפתח נשמר בלשונית הזו בלבד.
- כל הודעה מוצגת עם העמוד שממנו נשלחה.
- עמודת "דפדפן" היא תווית קצרה וקבועה לכל דפדפן. היא לא חושפת את המרחב שלו.

## מה לדעת לפני ששולחים לחברים

| נושא | המצב |
|---|---|
| שמירת נתונים | הנתונים נמחקים בהפעלה מחדש של ה-Space או בפריסה מחדש. לשמירה קבועה מחברים ל-Space אחסון (Storage Bucket), שמוצב ב-`/data` (בתשלום; את המחיר יש לבדוק באתר). אחרת: "ייצוא גיבוי" בכל פרויקט |
| שינה | Space חינמי נרדם אחרי תקופה בלי שימוש, והכניסה הראשונה אחריה איטית (דקה בערך). המשך הזמן לפי מדיניות Hugging Face, שאינה בשליטתנו |
| עוגיות | חלון גלישה בסתר, או מחיקת עוגיות, מאבדים את המרחב. קישור "המשך ממכשיר אחר" מחזיר אותו, כל עוד השרת לא אותחל |
| ביצועים | CPU basic משותף. סימולציה רגילה לוקחת פחות משנייה; ניסויי מעבר וכיול לוקחים כמה שניות |
| אבטחה | אין סיסמאות. מי שמחזיק קישור מרחב מחזיק במרחב. אסור להכניס מידע רגיש |
